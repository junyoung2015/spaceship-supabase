# v0.2 beta acceptance report template

- **Status:** reusable, unpopulated decision template for [issue #15](https://github.com/junyoung2015/spaceship-supabase/issues/15).
- **Audience:** the release owner preparing a possible beta.4 gate; beta.4
  tester authorization is still pending, and any wider audience requires a
  separate board decision.
- **Product status:** this template is not release evidence and does not
  authorize beta.4 or external testing, even when the `v0.2.0-beta.4`
  private-dogfood candidate is tagged. `v0.2.0-beta.1` is immutable, rejected,
  and unpublished after its failed release gate; `v0.2.0-beta.2` is immutable
  but superseded for current-style sync; beta.3 is immutable. None is report
  evidence or an install target without a reviewed prerelease.
- **Scope:** top-level `synced:project` v0.2 evidence plus beta.4's documented
  host-owned default registration placement and default `at ` target/context
  prefix. beta.4 retains the beta.1-defined sync scope and
  [#27](https://github.com/junyoung2015/spaceship-supabase/issues/27)'s bounded
  current-CLI envelope repair. Hosted-branch sync is post-v0.2 work in
  [#13](https://github.com/junyoung2015/spaceship-supabase/issues/13); the
  `linked-project.json` telemetry snapshot is a recorded no-go in [#5](https://github.com/junyoung2015/spaceship-supabase/issues/5).

The board has used **“Dongtan report”** as an internal working label for this
report. It has no imported meaning, audience, metrics, or terminology. An
explicitly authorized beta.4 gate may populate this template under its ordinary
title; do not distribute or rename it as a Dongtan report without a separate
board definition.

## Known limits and exclusions

- A synced project decoration is a user-confirmed point-in-time record, not a
  prompt-time network freshness claim.
- The full validated live ref remains identity; manual labels and synced text
  are decorations only.
- `supabase/.temp/linked-project.json` is not a v0.2 or first-external-beta
  source.
- Hosted-branch sync and `synced:hosted-branch` output are excluded from v0.2.
  [#13](https://github.com/junyoung2015/spaceship-supabase/issues/13)
  remains post-v0.2 discovery with its own demand, exact-match, state-schema,
  rollback, and release gates.
- A plugin checkout does not edit `.zshrc`. Upgrading from beta.3 or rolling
  back beta.4's physical layout may therefore require a separate, explicit
  prompt-order configuration change.
- Unsupported, unsafe, malformed, ambiguous, or insecure local state fails
  closed or omits only optional decoration according to the product contract.
