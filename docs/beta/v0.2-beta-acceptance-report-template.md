# v0.2 beta acceptance report template

- **Status:** reusable, unpopulated decision template for [issue #15](https://github.com/junyoung2015/spaceship-supabase/issues/15).
- **Audience:** release reviewers after the board completes the decisions below.
- **Product status:** this template does not claim that v0.2 beta behavior has shipped.
- **Scope:** top-level `synced:project` beta.1 evidence only. Hosted-branch sync is later work in [#13](https://github.com/junyoung2015/spaceship-supabase/issues/13); the `linked-project.json` telemetry snapshot is a recorded no-go in [#5](https://github.com/junyoung2015/spaceship-supabase/issues/5).

The board currently uses **“Dongtan report”** as an internal working label for
this report. It has no imported meaning, audience, metrics, or terminology.
Do not populate, distribute, or rename a report as a Dongtan report until the
board records the decisions in the next section.

invite testers or direct a suspected vulnerability report until the board has
chosen and verified a real private reporting route. A normal public issue is
never a substitute, and security findings do not belong in ordinary feedback.

and use the board-approved confidential channel once it exists.

## Known limits and exclusions

- A synced project decoration is a user-confirmed point-in-time record, not a
  prompt-time network freshness claim.
- The full validated live ref remains identity; manual labels and synced text
  are decorations only.
- `supabase/.temp/linked-project.json` is not a v0.2 or first-external-beta
  source.
- Hosted-branch sync is excluded until [#13](https://github.com/junyoung2015/spaceship-supabase/issues/13)
  supplies its separate exact-match proof and release gate.
- Unsupported, unsafe, malformed, ambiguous, or insecure local state fails
  closed or omits only optional decoration according to the product contract.
